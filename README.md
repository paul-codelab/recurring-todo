# 我的待辦事項

**中文** | [English](README.en.md)

一個檔案就能用的個人待辦清單。不用安裝、不用註冊、不用架伺服器，用瀏覽器打開 `index.html` 就能開始。

特別適合**週期性的例行工作**，尤其是一年只做一兩次、每次都有固定步驟的事，例如年度報稅、保險續約、健康檢查、各種定期申報。

![主畫面](screenshots/screenshot-main.png)

## 為什麼做這個

工作上很多每週、每月、每年的重複事項，但是常常：

- 在 Google 日曆設好重複提醒，但通知跳出來時已經來不及準備；
- 在待辦事項軟體上先設好，但一整年都佔著版面；
- 或者乾脆忘記設，到期前才想起來。

這個工具的做法是**週期休眠**：週期任務完成後，下一期會先收進「排程中」，到期前 N 天才自動浮上清單（預設每天 0 天、每週 3 天、每月 7 天、每年 30 天，可逐項調整）。

![排程中](screenshots/screenshot-scheduled.png)

## 功能

- **週期任務**：每天／每週（指定星期）／每月（指定日，含月底）／每年（指定月日），可設結束日期；下一期可依「原定期限」或「實際完成日」推算
- **週期休眠**：未到時間的下一期放在「排程中」，時間到自動浮現，並標示 🆕 新排入
- **細項清單**：每個任務可以有細項，週期任務每次重新開始時細項自動重設
- **狀態篩選**：全部／逾期／今天／7 天內／無期限／排程中，逾期一律置頂
- **自訂標籤**：可新增、改名（自動套用到所有事項）、調整順序、刪除，並隨 JSON 備份一起保存
- **重要程度、搜尋**（搜尋包含已完成任務與細項內容）
- **已完成紀錄**：可回顧當時勾了哪些細項，一鍵「再做一次」
- **複製一份**：臨時要多做一次時，直接複製現有任務
- **淺色／深色主題**，手機與電腦版面自動適應

## 資料存在哪裡

所有資料只存在**你自己的瀏覽器**（localStorage），不會上傳到任何地方。也因為這樣，請注意：

- 換瀏覽器、換電腦、清除瀏覽資料，資料就看不到了；
- 建議到「💾 資料」面板**綁定一個自動備份檔**（Chrome／Edge 支援），之後每次異動都會自動寫入；放在 OneDrive、Google Drive 等同步資料夾更安全；
- 也可以手動匯出／匯入 JSON，或匯出 CSV 給 Excel 閱讀。

## 使用方式

**線上試用**：https://paul-codelab.github.io/recurring-todo/

**本機使用**：下載 `index.html`，用 Chrome 或 Edge 直接開啟即可。

第一次開啟會載入示範資料，看完後到「💾 資料」面板底部按「清空資料」，就可以開始放自己的任務。

> 小提醒：用 `file://` 開啟本機檔案時，所有本機網頁共用同一個儲存空間。如果你自己複製一份改版，請記得修改程式裡的 `KEY`，避免兩個版本的資料互相覆蓋。

## 技術說明

- 單一 HTML 檔，純 JavaScript，無任何外部相依套件或 CDN
- 自動備份使用 File System Access API（Chrome／Edge），檔案權限存在 IndexedDB
- 其他瀏覽器仍可使用，只是沒有自動備份，改用手動匯出
